 VALORANT WEAPON CATALOG

Deskripsi Aplikasi
Aplikasi Android sederhana berbasis Kotlin yang digunakan untuk mencari dan mengurutkan data senjata pada game VALORANT.  
Project ini dibuat untuk memenuhi tugas Ujian Akhir Semester (UAS) Pemrograman Seluler menggunakan metode Project-Based Learning (PBL).

Fitur Aplikasi

Modul 2 & 3
- UI Responsive Portrait & Landscape
- Desain modern bertema VALORANT

Modul 4 & 5
- Intent antar halaman
- Validasi input menggunakan If-Else

Modul 6
- Struktur data Array
- Linear Search untuk pencarian senjata

Modul 7
- Bubble Sort A-Z
